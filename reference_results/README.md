# Reference non-vision results

This directory contains compact outputs from the completed full protocol:

- 861 of 861 planned runs completed.
- No run failures were recorded.
- `final_runs.csv` contains one row per completed run.
- `gradient_validation.csv` and `relaxation_validation.csv` contain the
  CAT/AR gradient-recovery audits.
- `overdamped_limit_validation.csv` contains the independent CAT-to-AR limit
  audit.
- `aggregate_comparisons.csv`, `paired_comparisons.csv`,
  `equivalence_tests.csv`, and `global_tests.csv` contain the reported
  statistical comparisons.
- `transport_probe_runs.csv` and `transport_probe_comparisons.csv` contain the
  non-vision finite-hop and transported-gauge controls.
- `suite_config.json` and `suite_metadata.json` record the protocol and
  software environment.

Large per-epoch histories, figures, and resumable checkpoints are not included
in this minimal repository. They can be regenerated by running the full
protocol. MNIST and CIFAR-10 outputs are also not included here. The commands
used to reproduce those optional probes are given in the main README.
