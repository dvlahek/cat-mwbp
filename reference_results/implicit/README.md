# Implicit/recurrent reference summaries

These CSV files are compact summaries of the standard runs reported with the manuscript.

- `spectral_asymmetry_audit.csv` records the spectral intervals and AR step sizes for the ordinary and asymmetric 2-D recurrent graphs.
- `core_dataset_summary.csv` contains the eight core/scaling classification summaries over three seeds.
- `vision_dataset_summary.csv` contains the MNIST and CIFAR-10 summaries over three seeds.

The experiment scripts regenerate the full run-level CSV files, solver audits, figures, configuration files, and reports. Those larger generated files are not committed here.
